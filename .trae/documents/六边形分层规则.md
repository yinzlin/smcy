# ADR：六边形分层规则

- 状态：已定稿（长期有效）
- 适用：本仓库全部 Rust crate（`crates/{common,domain,database,application,backend}`）
- 目的：把「严格六边形」固化为可执行的判定标准，作为后续长期开发的硬约束。

## 背景

项目重构为 cargo workspace 后六边形骨架已立，但依赖规则仍存在穿透（application 直接依赖 database/sqlx 并执行裸 SQL、backend 中间件绕过端口直连 connection pool、HTTP 契约落在 domain）。为使该骨架可长期深耕，需以 ADR 形式明确边界。

## 决策

### 1. 依赖方向白名单

| crate | 允许依赖 | 禁止依赖 |
|---|---|---|
| `common` | 无业务 crate（仅通用库） | 其他业务 crate |
| `domain` | **仅 `serde`** | 其余全部 |
| `database` | `domain`、`common` | `application`、`backend` |
| `application` | `domain`、`common` | **`database`、`sqlx`**、`backend` |
| `backend` | `application`、`database`、`common` | —— |

`crates/frontend` 为独立 npm 工程（exclude 出 workspace），产物由 backend 经 rust-embed 编译期内嵌，不参与 Rust 依赖图。

### 2. 持久化访问唯一路径

- `database::pool()` 与任何 `sqlx::` 调用**只允许**出现在 `crates/backend/src/di.rs`（唯一组合根，负责 test/prod 池注入）。
- `database` 之外的任何 crate 一律通过 `domain::port` 出站端口访问持久化；`application` 通过构造注入的 repo 句柄（泛型单态化）访问。
- `backend` 中间件/处理器不得直连 pool，必须经端口取数。

### 3. 契约归属

- HTTP 请求体结构体（`*Req`）归 `application/src/dto`，不属 domain。
- domain 出站端口的出入参一律使用 domain 自有类型（Row 结构体 / 输入结构体），**不携带 serde 反序列化职责**。
- 应用层入站端口（`application/src/port`）可使用 `application::dto` 类型。
- `UserCtx` 保留在 domain：它是被多域共享的会话上下文领域概念，非 HTTP 契约。

### 4. 错误映射链（单向，不逆转）

```
DomainError(thiserror, 4 变体: NotFound/InvalidInput/Conflict/Storage，无 HTTP 语义)
  └─ From<DomainError> for UseCaseError
UseCaseError(7 变体: Business/BadRequest/Unauthorized/Forbidden/NotFound/Storage/RawResponse)
  └─ backend 适配器映射为 HTTP 状态码
```

HTTP 状态码与错误文案由 backend 适配器唯一决定；下层不引入 `StatusCode`。

### 5. 接口兼容红线

- 所有响应/请求 JSON 的字段名与顺序不得改变（`serde` 序列化顺序 = 字段声明顺序）。
- `scripts/smoke.ps1` 的 232 条断言为行为不变性基线，任何整改后必须全通过。
- 金额一律 `f64`、日期一律 `String('YYYY-MM-DD')`；不引入会改变 JSON 形态的强类型值对象。

## 后果

- 正向：依赖规则零例外，领域层纯净，替换持久化实现或新增适配器不改业务层。
- 负向（可接受）：新增查询需「定义端口 → 实现 repo」两步；application 不能图省事直连 SQL。
- 明确不做：不补齐 DDD 战术模式（Aggregate/ValueObject/DomainEvent）；不引入 dyn 抽象；不换数据库；不恢复模板空目录。

## 强制校验

见 `scripts/check_layers.ps1`：断言 `domain/Cargo.toml` 依赖仅 serde、`application/src` 无 `pool()`/`sqlx::`、非 `di.rs` 的 backend 无 `pool()`、`domain/src` 无 `*Req`。
